## 1. What I Learned

During this project, I learned how to build a website using Next.js and React. I worked with components, props, state, routing, and API integration. I also learned how to use React Hook Form for input validation and how to deploy a project using GitHub and Vercel.

## 2. Challenges I Faced

One of the main challenges was getting artwork images to display properly. Some artworks did not have available images, so I had to improve how the application handled those results.

I also faced an API issue because the older Met Museum search endpoint was no longer working. After identifying the error, I updated the endpoint and tested the search again.

Another challenge was the CSS not loading correctly. I checked the project structure, restored the styling, and tested the application in the browser.

## 3. How I Solved the Problems

I tested the application regularly and checked the errors whenever something was not working. I used ChatGPT for guidance and suggestions, then made changes in VS Code and checked the results.

I also ran `npm run build` to make sure the project could build successfully before deploying it.

## 4. What I Completed

I completed the Home, Artworks, Advanced Search, Artwork Details, and About pages. The application allows users to search for artworks, view available images, and open individual artwork details.

I added form validation, handled loading and error messages, and used responsive styling. I also pushed the project to GitHub and successfully deployed it to Vercel.

## 5. What I Would Improve

If I had more time, I would add more search filters, such as artist, department, and artwork date. I would also improve the loading speed and add more features to help users explore the museum collection.
